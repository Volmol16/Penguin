# ESP32-S3 AI-игрушка — локальный голосовой ассистент

Голосовая игрушка на ESP32-S3 с полностью локальным пайплайном распознавания
речи, LLM и синтеза голоса (без обязательной облачной зависимости), wake
word на устройстве и анимированными глазками на OLED. Разработка ведётся
поэтапно: каждый шаг проверяет один рискованный компонент в изоляции, прежде
чем объединять его с остальными.

## Структура репозитория

```
firmware/     — прошивка ESP32-S3 (PlatformIO + ESP-IDF), по шагам
  step1_tflite_check/   — проверка тулчейна TFLite Micro (синтетическая модель)
  step2_frontend_check/ — проверка аудио-фронтенда (синтетический тон)
  step3_live_wakeword/  — wake word "Ирина" на реальном микрофоне
  step4_oled_eyes/       — диагностика при старте + анимированные глазки
  step5_merged/          — Step 3 + Step 4 вместе
server/       — PC-сервер: STT (faster-whisper) -> LLM (Ollama) -> TTS (Silero)
  pc_server.py
  character_pack.py      — система персонажей (голос/характер/возрастной сегмент)
  speaker_id.py           — распознавание голоса (экспериментально)
  web_search_module.py    — поиск в интернете через SearXNG (заготовка)
  characters/             — примеры персонажей (не лицензированные франшизы)
tools/        — вспомогательные скрипты для ПК (не часть прошивки)
  tflite_to_header.py          — .tflite -> C-заголовок для прошивки
  check_wakeword_model.py      — проверка модели по тензорам
  test_wakeword_realworld.py   — проверка модели на реальных .wav (тот же TFLite C API, что и на плате)
  generate_test_audio.py       — генерация тестовых .wav через Silero TTS
  convert_to_16k_mono.py       — приведение любых записей к 16кГц моно
docs/         — дорожная карта и гайды по каждому шагу
```

## Статус разработки

| Шаг | Что проверено | Статус |
|---|---|---|
| Step 1 | PlatformIO + ESP-IDF + esp-tflite-micro собирается и работает на плате | ✅ подтверждено на железе |
| Step 2 | Аудио-фронтенд (микрофронтенд TFLM) считает признаки на реальном железе | ✅ подтверждено на железе |
| Step 3 | Модель "Ирина" детектит реальный голос через I2S-микрофон | ✅ модель проверена на ПК (синтетика + живой голос), прошивка готова к проверке на железе |
| Step 4 | OLED-диагностика + глазки с эмоциями/морганием | ✅ отрисовка проверена рендером, готово к проверке на железе |
| Step 5 | Step 3 + Step 4 вместе | ✅ готово к проверке на железе |
| Step 6 | WiFi + OTA-обновление прошивки + доступ к файлам (LittleFS) | 🚧 в разработке |
| Дальше | Полный пайплайн: WebSocket к `server/pc_server.py`, воспроизведение, перебивание | не начато |

См. `docs/ROADMAP.md` — бизнес-контекст, архитектурные решения и то, почему
сделано именно так (офлайн-деградация L0/L1/L2, авторские права на
персонажей, сертификация детских товаров и т.д.).

## С чего начать

1. `docs/ROADMAP.md` — общая картина и почему проект устроен именно так.
2. `docs/STEP1_GUIDE.md` … `docs/STEP5_GUIDE.md` — по порядку, каждый
   следующий шаг объясняет, что он добавляет к предыдущему.
3. `docs/WAKE_WORD_GUIDE.md` — отдельно про выбор/обучение wake-word модели.

## Важно

- Реальные WiFi-пароли и прочие секреты **не должны** попадать в git — см.
  `.gitignore` (добавится в Step 6 вместе с WiFi) и используйте
  `*_credentials.h`/`.env`, которые туда уже внесены.
- Персонажи в `server/characters/` — намеренно оригинальные, не
  лицензированные франшизы (см. `docs/ROADMAP.md`, раздел про авторские
  права).
